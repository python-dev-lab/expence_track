Веб-приложение отслеживания личных затрат, где пользователи  могут добавлять свои расходы и доходы, просматривать статистику и управлять своим бюджетом. В БД будут храниться информация о каждом пользователе и их расходы и доходы.
Технологии
Flask 3 + Flask-Login + Flask-SQLAlchemy + Flask-WTF

Bootstrap 5, Chart.js

SQLite
